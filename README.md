# With the Devilish Her — Russian Translation

Неофициальный фанатский перевод. Проект не содержит игру целиком: патчер применяет перевод к вашей собственной копии.

## Скачать

Готовый архив лежит в разделе **Releases** этого репозитория:

- `WDH_RU_Patcher_vX.Y.Z.zip`
- рядом публикуются `SHA256SUMS.txt` и исходный код

Нужна точная поддерживаемая версия игры. После обновления игры патч может отказаться работать — это защита от порчи файлов.

## Установка

1. Закрой игру.
2. Распакуй архив в обычную папку на `C:` — например, на Рабочий стол или в Загрузки.
3. Запусти `WDH_RU_Patcher.exe`.
4. Выбери папку, где лежит `WithTheDevilishHer.exe`.
5. Нажми «Проверить», затем «Установить перевод».

Перед изменением файлов создаётся резервная копия `WDH_RU_Backup` в папке игры.

## Удаление

1. Закрой игру.
2. Запусти тот же `WDH_RU_Patcher.exe`.
3. Выбери папку игры и нажми «Удалить перевод».

Патчер восстановит исходные файлы, проверит их SHA-256 и удалит `WDH_RU_Backup` и временные файлы. В папке игры не остаётся мусора.

## Важно про предупреждение Windows

`.exe` пока не подписан, поэтому Windows может показать предупреждение о скачанном файле. Это не детект вируса, а стандартная пометка «файл из интернета».

- Перед распаковкой открой свойства zip-архива и нажми «Разблокировать».
- Если предупреждение всё равно появилось: «Подробнее» → «Выполнить всё равно».
- Проверь `SHA256SUMS.txt` из релиза.
- Исходный код патчера открыт в папке `patcher/`.

Подпись кода планируется отдельно; самоподписанный сертификат использовать нельзя — он только добавит «Неизвестный издатель».

## Что изменяется

- `WithTheDevilishHer_Data/Managed/Assembly-CSharp.dll`
- `WithTheDevilishHer_Data/resources.assets`
- `WithTheDevilishHer_Data/resources.assets.resS` — только область изображения About
- `WithTheDevilishHer_Data/level1`
- `WithTheDevilishHer_Data/StreamingAssets/DLC_FULL/dlc_scenario`
- `WithTheDevilishHer_Data/StreamingAssets/DLC_FULL/dlc_text_patch.json`

Телефонные чаты `DLC_FULL/dlc_cg` не изменяются и пока остаются английскими.

## Прозрачность

- Патчер не использует сеть, реестр, службы и не требует прав администратора.
- Все изменяемые файлы перечислены в `patcher/manifest.json` с размерами и SHA-256 до/после.
- Перед установкой создаётся видимая резервная копия.
- Есть проверка целостности патчей и итоговых файлов.
- Исходник: `patcher/patcher.py`.
- Проверка без изменений: `WDH_RU_Patcher.exe --check --game "путь к игре"` или `--dry-run`.
