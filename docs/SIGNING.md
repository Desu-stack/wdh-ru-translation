# Подпись кода

Windows предупреждает о скачанных неподписанных `.exe`. Это не вирус, но пользователей это отпугивает.

- **Не используй самоподписанный сертификат** — будет «Неизвестный издатель».
- **OV-сертификат** дешевле, но репутация SmartScreen набирается постепенно.
- **EV-сертификат** даёт доверие сразу, но стоит дороже.
- Для open-source можно подать заявку в **SignPath Foundation** и подписывать сборку в GitHub Actions.
- Подписывай именно `.exe`; не пересобирай файл после подписи.

Пока подписи нет, в README нужно оставить инструкцию:

1. Свойства zip → «Разблокировать».
2. Распаковать.
3. Сверить `SHA256SUMS.txt`.
4. Запустить и при предупреждении выбрать «Подробнее» → «Выполнить всё равно».
